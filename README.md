# Brandons-Course-Enroller
This programm automatically enrolls you into the given Courses at a specific time.

This application is made for the campus system "StudIp" and doesnt work for other systems.
It was only tested on the StudIp System of the university "Hochschule Flensburg"

## Installation
### Linux
1. Download "course-enroller.deb" from `/linux/build/`
2. Install the package (you might have to change the rights for it by using `chmod +x course-enroller`)
3. Now you can run the application from the terminal by typing `course-enroller` or look for the application on your system

### Windows
1. Download "course-enroller.deb" from `/windows/build/`
2. The Application is ready to go. Just open the application
